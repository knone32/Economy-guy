# Economy-guy · 财税 Agent 工作台 · 初赛 v2.0.2

Economy-guy 是云帐房 2026 AI 技术创新大赛赛题二的初赛作品。工作台支持自然语言查询、发票用途规则核查、受控发票修改和持久待办。模型理解请求并提出工具调用，程序核验范围和权限，按 SQLite 当前数据计算、保存和审计。

## 启动与演示

完整解压运行包，在 Windows 双击 `START.bat`。需要 Python 3.11 或更新版本。缺少依赖时选择 **3**，程序会在项目目录内创建虚拟环境并按依赖清单安装。

- **1 · Live 工作台**：导入官方虚构 Excel，以 U001 登录，配置自己的真实模型。发票修改和待办创建需核对预览后人工确认。通过「记录」展开实际工具、规则和可关联的提交审计及回读证据。
- **2 · 离线 Mock**：使用固定模型提案和独立虚构账簿，执行真实本地业务工具，模型 API 请求为零。输入框上方有财务查询、规则知识库、发票操作、任务与记忆、安全与审计五类预置请求。

建议将终端最大化至 137 列以上。紧凑模式可通过「查看业务历史」访问结果。官方百炼可用 OpenAI 兼容 Provider、账号所在地域的 HTTPS SDK Base URL 和 `qwen3.8-max` 的 `auto` Profile。连接检测只核对接口连通和工具调用，当前冻结版的真实三场景业务验收仍待人工完成。

## 初赛业务范围

R001 分别统计发票价税合计、银行收入和支出。正式用途检查限 2026 年 9 月，甲企业用 R002 v2.0，乙企业用 R003 v1.0。跨账期按指定规则重新筛选属于参考分析。银行流水只读，无法据此判断具体发票是否付款。发票仅允许修改用途和备注，实际提交以事务审计和回读为准。

作品使用官方 1.1.0 虚构 Excel 与比赛模拟账号。U001 可读写两家企业，U002 只可读取甲企业。交付包内的 Excel 用于初始化独立账簿。
