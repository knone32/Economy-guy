# TUI → GUI 功能入口清单

本包使用 E:/beside 的代码和公开配置。GUI与TUI共用原 Agent.ask、SessionHost、SessionStore、任务/偏好/资料服务及确认渠道，GUI不另设业务 owner。

| TUI功能 | GUI位置及执行依据 |
| --- | --- |
| 自然语言查询、单票/多票修改、追问补值、改口 | 对话；复用原语义入口、白名单、范围来源及事实覆盖检查 |
| 预览、本人确认、取消、未知提交只读核查 | 原预览弹窗与回执；批准不能由正文或浏览器自报权限替代 |
| 历史对话、新建/切换、执行记录 | 对话侧栏、记录页；历史明确标为当时记录，不当作当前事实 |
| 等待补值、暂缓、恢复、取消 | 待办页原候选/修订；不复用旧批准 |
| 持久任务详情、进入办理、新建/补充/更正/等待/暂缓/恢复/完成/取消 | 待办页任务管理；原任务策略及Management确认，完成须事实支持 |
| 发票目录、月/年/全部范围、排序/分页、单票详情 | 业务查询；原Schema/ACL/范围证明，渲染后ACK登记原可信锚点 |
| 银行收支、金额汇总、用途缺项、年度汇总/空用途/收入 | 业务查询；金额单位与空期/拒绝分开；银行只读 |
| 适用规则与规则版本 | 业务查询；原规则服务 |
| 资料上传/更新、目录、精确版本来源单元 | 业务查询资料区；docx/xlsx/文字PDF，原权限及不可变版本，上传不是规则发布 |
| 既有业务助手、个人/企业偏好 | 业务查询；偏好更改仍预览确认，不授予业务权限 |
| 当前模拟账号权限、账号切换、退出 | 设置的宿主绑定/退出；是本机模拟，不是登录认证 |
| 已有账簿、Excel导入、旧库备份升级 | 设置；原生文件选择器登记，宿主不透明选项重绑定，原导入/升级器；不覆盖当前库 |
| Profile列表/切换/个人新增编辑、设置密钥、忘记密钥 | 设置；原配置校验及Windows凭据库；模板/全局配置不允许伪装为个人覆盖 |
| 检查连接、固定脚本Mock、下一轮结构诊断 | 设置；连接检查仅用户点击才联网，最多两个合成请求；Mock不算Live |
| 规则及高级CLI入口 | 设置“规则与高级控制台”；与TUI原入口相同，安全关闭GUI owner后转原控制台，不是新建图形规则编辑器 |
| 复制启动命令 | 设置；包含EXE、账簿、会话和公开配置路径，不含密钥，新进程使用自动端口 |

## 证据与范围

本轮新增五项程序检查及两项架构检查通过：任务管理预览取消、资料版本/原文/跨用户拒绝、本机重复绑定与新库登记、网页令牌不能调用原生选库、忘记密钥取消及个人配置编辑。年度/全账期对照首轮发现零值被当作日期限制，修正薄适配对零选择器的表示后通过；原范围核验保留。

源码真实WebView2窗口已观察到页面，并从实际查询按钮交付10张发票、登记展示ACK；导航及UI双就绪收到。首轮曾误带旧原生二进制，超时失败原件保留，按绝对路径重新编译后修复。最终EXE的独立解压启动结果见同目录交付核对记录。

这些是程序与自动窗口证据，不是Live自然语言成绩或真人批准验收。未为验证界面重跑旧提交链、未代点批准、未调用连接探针。历史自然语言链仍保留原失败，不声明任意说法均能完成。

## 启动与恢复

解压后双击EconomyGuy.exe，等待内嵌窗口；无需安装Python。需Windows 10/11 x64、.NET Framework 4.6.2+及Microsoft WebView2 Runtime。缺API密钥仍可打开设置与只读查询；公开Profile已预置，实际密钥由同Windows用户凭据库或本机指定环境变量取得，不随包分发。

data/demo.sqlite3是预制官方虚构账簿；首次启动创建独立会话库。运行数据和日志保存在EXE旁。退出前先处理运行请求/预览/待补/未知提交；异常重启先恢复或只读核查，不盲目重提。旧包与首次失败保存在开发目录artifacts，不混入本包。

最终候选3a483ab独立解压的无参数EXE已双就绪，实际发票查询与展示ACK通过，任务补充预览/取消可达；未批准、发票/审计未改。该次人眼截图发现任务预览直接显示参数JSON，后续仅将其改为企业/账期/操作/当前状态和新旧说明，原提案指纹及确认机制未变。新增程序断言确认不再显示task_id参数；首次断言误用预览body键导致测试ERROR，改用原接口text后核对，不修改原失败记录。
