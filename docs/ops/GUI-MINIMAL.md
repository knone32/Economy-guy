# 最小可交付 GUI：运行与验收清单

基线：`sprint/2026-11-20-contract-followup` / 本轮冻结提交（Sol 的
`SessionHost` display-ack 与超时契约在 `426f7b2` 已提供；受测业务源码
`1a05bc9`）。本 GUI 未修改 `session_host.py`、`session_store.py` 或任何业务
核心文件；只消费原 host 接口。最终冻结 SHA 以 `git log -1` 为准。
本文件只描述本 GUI 的本地接线，不迁移旧 TUI/Live 成绩，不新增业务判定。

## 启动

```powershell
cd finance_agent
python run_gui.py --db <已有工作库.sqlite3> --user U001 --open
```

或从仓库根双击 `START-GUI.bat`（可追加同样的参数）。需要已有本地模型
Profile；首次可加 `--profile <名称>`，Profile 不在默认 `config/` 时加
`--profiles-local <路径>`。默认绑定 `127.0.0.1:8765`，**不是远程服务**。

## 真人验收（必须本人执行，不能由程序代签）

状态：**NOT_RUN**。由真人使用自己的账号/账簿/Profile 操作并签字；Agent 只准备页面和记录，
**不替真人点击确认、不把脚本结果写成 Live/真人成绩**。建议一次只核对下面
一个路径，保留工作库/审计/回执截图；同一节点不重复执行。

1. 用已有 profile 打开本机 GUI；确认账簿/账号/模型连接。
2. 发送一条真实查询（例如“汇总甲企业 2026 年 9 月发票和银行收支”），
   看清对象、范围、金额单位“元”、张数/条数，确认卡片与聊天可见。
3. 在**同一页面**紧接着发指代续办（例如“刚才那张发票的用途也看一下”或
   “把刚才那张的备注改成……”），核对是否仍指向同一企业/账期/票据；若不
   唯一，页面必须要求补充，不能自行猜。
4. 发送一条明确的单票修改（例如“把甲企业 F002 的用途改成资料打印”），
   在预览中核对企业、账期、票号、字段、原值/新值，然后本人点“确认保存”。
5. 查看提交回执：COMMITTED 且新连接回读核实；如果显示未知，只点“核查”，
   不重复提交。若聊天历史保存失败，单独记录该失败，不能改写成提交失败。
6. 另造一个待补候选，点击“暂缓”；若保存失败，确认页面显示失败且**没有**
   可恢复按钮/“已暂缓”提示。成功暂缓后关闭/重开页面，从“可恢复候选”恢复；
   确认恢复后仍需重新核权并生成新预览。
7. 取消一次未确认预览，确认没有新增提交/审计。
8. 若本轮可观察确认超时：等弹窗失效后确认窗口已关闭、忙碌已解除、页面明确
   显示“未批准/未提交”；刷新页面或点旧按钮不得再次出现可操作预览，也不能
   新增提交/审计。此步骤由真人观察，不由脚本代签。

签字记录（真人填写）：

预览字段核对（对象/账期/票号/字段/原值/新值/确认按钮）：____
回执状态/回读：____  未知回执核查：____  暂缓失败提示：____

## Live 消耗与不重复执行

本轮没有调用真实模型 API：**0 个模型请求 / 0 tokens**（只有本机页面请求），
没有重跑 Sol 已验收的旧完整链，也没有把脚本测试当作 Live。后续如执行 Live，
**不设本地额度上限**，
与 Sol 共用同一消耗账本（`docs/ops/STATE.md`/Sol 记录）登记；同一已验收节点
不重复执行，只补 GUI 未验收的查询后续办、暂停失败提示、未知提交恢复交接。

- 使用脚本模型驱动真实 SQLite 的发送、预览、确认、取消、暂缓/恢复/切换已冒烟；
  另用短确认超时验证了弹窗关闭、忙碌解除、`EXPIRED` 未批准提示和旧句柄拒绝。
  以上都没有调用模型 API，未跑全量回归。
- 本机现有候选 Profile 未通过完整 `KEY/BASE_URL/MODEL` 校验，因此没有启动
  真实模型 Live；这不影响上面“程序接通”的结论，但不能当作真人验收。

## 未验收/未接通

- 真实模型 Live、真人完整可读性、自然网络故障、跨进程未知提交恢复。
- 多票/规则批量确认：当前明确拒绝生成预览；不伪造批量批准。
- 远程认证、远程确认、移动端、主题系统：不在本轮范围。
- `SessionHost` 是当前唯一命令 owner；没有生产 HTTP/认证/远程确认。GUI 的
  HTTP/异步确认桥仍是本机适配，不是 Sol 已签收的远程接口。
- 全量回归未跑；旧 TUI 已签收链不重跑。
