# 初赛冻结后的开发交接

`preliminary-2026-v1.0.0` 固定初赛演示基线。日常开发继续从 `main` 出发，历史报告、脚本与工程测试源码均保留。发布资产、冻结分支和 Tag 对应关系见[发布说明](PRELIMINARY-RELEASE.md)。

- 已具备范围鉴权后的金额查询和规则核验、人工确认后的修改及审计回读、独立持久待办、目录及多轮引用。用户真人证据及历史限制见[验收记录](LIVE-ACCEPTANCE.md)。
- 保留单一 Agent 循环、ScopeProof、SQLite 权威事实、按账号与账簿隔离的本地会话。恢复线索不产生写入授权，模型输出不构成执行回执。
- 上线前仍需验证近期新增的排序和新对话入口在目标终端的表现。正式评审环境、模型额度及提交回执由负责人核对。
- 后续改动关注工作台可读性、模型收尾表达和授权前提明确的管理能力。业务规则、确认、审计及权限边界继续沿用；冻结版修订需新版本。
