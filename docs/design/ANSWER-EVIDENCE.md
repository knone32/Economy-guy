# 当前事实与模型编排

模型继续自主选择工具及步骤。每次请求提供程序生成的 `answer_catalog`：引用绑定本轮 trace、实际工具结果、可信字段标签、企业/账期和值，另有实际操作回执。最终 `information` 或 `clarification` 可带 `answer` 字符串列表，模型决定所需事实及顺序；不能自写指标标签、数值或保存状态。未知、跨轮、重复或结构错误引用整组拒绝。原始自由正文仍保留 Trace，不因数字曾出现就成为业务事实。

旧信息信封无有效引用时，仍显示实际工具结果，并明确尚未核实是否满足全部要求；不把正确已执行查询清空，也不宣称整体完成。一般知识保持显式未核实标识，既有受限事实解释仍走原验证。任意自由比较或归因并未获得通用语义证明，复杂计算可用已有 SQL 工具，不能以别名伪装业务指标。

SQL 的授权快照执行和查询语义归因是不同证据。UNKNOWN 只可交付实际 SQL、快照范围、列与原始值及限制，不能升级为完整筛选/全集/单位证明。原生发票目录增加 `sort_by=invoice_no`，适用于年度/月度按票号分页及真实总数，无需为这一普通排序目标构造嵌套 SQL。

`turn_action="stop"` 是模型声明的当前轮终止动作，清除未提交草稿/待补并停止；不撤销已提交数据或持久任务。一般转述中标准企业、日期、票号可补充 `get_invoice` 缺失的只读来源；已有明确或可信引用优先，多企业/账期无法可靠配对或冲突时不补，引用中的公司、年月、新值不能因此进入写入证明。Handler 仍重新鉴权并核对当前票据日期，Prepare/提案/确认/事务/幂等/审计/回读未改。

当前SQL若有既存真实发票投影、无SQL分页/展示截断且企业与票号联合键唯一，可从该次实际行集派生分企业发票数和两企业计数差额ref，父引用仍指向原结果。标签始终是“本次返回明细”，不把授权全集覆盖与完整筛选集混淆、不把UNKNOWN或任意列别名升级为语义证明。权限拒绝只说明本操作所需权限不足，不从一项拒绝推断所有读取及修改权限均无效。

这些是程序契约；脚本控制不计自然语言能力。原测试的自由正文原样显示断言未删改，兼容性变化须报告。是否能处理新表达须在完整 SHA 冻结后以真实模型、独立真值和首次执行验收。

## 有限派生与输入投影

`answer` 可包含 ref 字符串，以及 `{"op":"compare","left":"当前ref","right":"当前ref"}` 或 subtract 两种条目。父事实须为当前轮运行时绑定的整型金额分/数量，指标来自原生字段或既存 VERIFIED SQL 表达式归属；任意 SQL alias、UNKNOWN 投影常量、文本、回执、跨轮或无效ref不能变成标量父事实。比较要求同指标口径、同粒度范围；不同金额指标仅可在同范围作明确标注两父指标的减法，不推断利润、回款或保存。程序负责算术、方向、范围、单位和标签，不接自由标签或嵌套表达式。

完整事实文本仍留在执行侧；模型请求的catalog只投影ref、类型、单位、必要标量、范围/父引用等紧凑元数据。原始工具消息、当前用户、pending、规则、权限及tool_call_id配对不因该投影删除。不宣称单靠此优化解决预算容量；不能以字符/字节差异充当真实token或能力收益。

预算守卫使用 `BudgetExceeded` 类型和安全数字元数据，SDK包装后仍按异常链中的类型识别，区分未发HTTP与网络/未知usage，不匹配错误字符串。Transport不重试或改工具可见性。唯一Loop可由其原预算owner决定有界收尾/真实结果fallback；无新授权不得提高额度。Thinking最终请求即使不提供新工具schema，也保留历史真实tool_call的实际reasoning字段；缺失字段不补造。
